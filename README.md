# ElitePortfolio - قالب موقع شخصي احترافي عربي

**أفضل قالب موقع تعريفي شخصي لعام 2026**

## المميزات
- تصميم فاخر RTL + Dark/Light Mode
- نموذج اتصال يعمل حقيقي (Formspree)
- زر تحميل السيرة الذاتية
- متجاوب مع الموبايل والتابلت
- سهل التخصيص لأي شخص

## خطوات التخصيص:
1. افتح `index.html` بـ VS Code
2. استبدل كل `[اسمك]` بمعلوماتك
3. غير روابط الصور
4. سجل مجاناً في [formspree.io](https://formspree.io) واحصل على Form ID
